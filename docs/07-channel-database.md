# Create a Channel Database extension

> [!NOTE]
> This article is coming soon.

Channel Database extensions customize the Commerce channel database, including the offline SQLite
database and the Commerce Scale Unit (CSU) database. The mobile app can reference a Channel
Database project to generate the offline SQLite database. Detailed authoring guidance will be
added here.

## Requirements

| Requirement | Value |
| ----------- | ----- |
| Target framework | `netstandard2.0` |
| Required NuGet package | `Microsoft.Dynamics.Commerce.Sdk.ChannelDatabase` (Windows-only build) |
